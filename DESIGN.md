# Waha Reminder design direction

Identity: a practical scheduling desk for Indonesian teams that send WhatsApp group reminders.

Personality: calm, precise, candid, and workmanlike. It should feel dependable without looking corporate or sterile.

Palette: warm paper neutrals provide a comfortable work surface, deep green marks primary actions and healthy connection states, and amber is reserved for items that need attention.

Typography: the local system sans-serif stack keeps dense forms and schedules readable across Windows, Android, and other common devices without an external font dependency. Tabular numerals distinguish WIB times.

Mood: a well-kept paper planner translated into a responsive operations console.

Dial: ENERGY 1 / RHYTHM 2 / MOTION 1

## Decision reasons

- Color: warm paper reduces screen glare, while green connects primary actions to confirmed scheduling rather than generic technology styling.
- Layout: the reminder queue receives the widest column because reviewing what will send is the main decision; the composer stays adjacent on wide screens and moves first on phones.
- Typography: system sans-serif type is familiar at small sizes and renders Indonesian copy consistently without loading an external asset.
- Spacing: a compact vertical rhythm supports frequent operational use, with larger gaps only between distinct tasks.
- Surfaces: flat bordered sections keep hierarchy legible; one elevated composer shows where changes are made.
- Status labels: text and shape accompany every color so delivery state never depends on hue alone.
- Motion: short state transitions confirm actions; no element moves continuously.
- Identity motif: WIB time blocks use tabular numerals and a strong baseline, echoing a physical appointment book.
- Icons: the interface uses direct text labels because no icon would explain these actions more clearly.
- Theme: a working theme switch supports daytime and low-light use because the product has no reason to force one theme.
